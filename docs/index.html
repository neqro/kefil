What is Kefil?

"Kefil" means guarantor in Turkish. Agent ID holders vouch for agents they trust and flag the ones that misbehave. Vouching puts your own reputation at stake: if an agent you vouched for gets flagged by 5 holders, your score drops too. The result is an open, on-chain trust score that any dApp on BNB Chain can read in one call to gate access, airdrops or payments.

Score = 10 × valid vouches − 10 × flags received − 15 × vouches given to agents that became risky. Only Agent ID holders can vouch, flag or be scored. No owner, no admin keys, no token, no funds held. Every action is a normal wallet transaction you confirm yourself.
